# מוריד פלייליסטים מיוטיוב (ZIP) - תוכנה ל-Windows

תוכנת שולחן עבודה יפה ומהירה: מדביקים קישור לפלייליסט, בוחרים מה להוריד, ומקבלים קובץ ZIP אחד.

- וידאו + אודיו / וידאו בלבד / אודיו בלבד (MP3, M4A, Opus, FLAC)
- בחירת איכות: עד 4K לווידאו, ו-128–320kbps לאודיו
- בחירת סרטונים ספציפיים מתוך הפלייליסט, תור הורדות, התקדמות חיה, היסטוריה
- הגדרות מסודרות: מראה (ערכת נושא, צבע הדגשה, אנימציות), הורדה (תיקייה, ZIP או תיקייה, מספור, מגבלת מהירות, הורדה מקבילית, עוגיות מהדפדפן), עדכון אוטומטי
- בלי להתקין Python, yt-dlp או FFmpeg, ובלי להקליד פקודות

**דף הנחיתה וההורדה:** https://hershale.github.io/download-youtube-playlists/

## למשתמשים

יש שתי גרסאות, והתכונות זהות:

| גרסה | למי מתאימה | הורדה |
|---|---|---|
| **מתקין** (`Setup.exe`) | רוב המשתמשים. קיצור בתפריט התחל ובשולחן העבודה, הסרה מההגדרות | [Setup.exe](https://github.com/hershale/download-youtube-playlists/releases/latest/download/Setup.exe) |
| **ניידת** (ZIP) | כונן נייד, מחשב ללא התקנות. מחלצים ומפעילים | [YTPlaylistDownloader-Portable.zip](https://github.com/hershale/download-youtube-playlists/releases/latest/download/YTPlaylistDownloader-Portable.zip) |

### התקנה
1. הורידו והריצו את `Setup.exe`. ההתקנה אישית ולא דורשת הרשאות מנהל.
   אם Windows מציג "Windows protected your PC": **More info** ← **Run anyway** (הקובץ לא חתום דיגיטלית).
2. התוכנה נפתחת בסיום ההתקנה. בפעמים הבאות: תפריט **התחל** ← *YouTube Playlist Downloader*.

### גרסה ניידת
1. חלצו את ה-ZIP לכל תיקייה (או כונן נייד) והריצו את `YTPlaylistDownloader.exe`.
2. ההגדרות וההיסטוריה נשמרות בתיקיית `data` לצד התוכנה. כדי להעביר מחשב, מעתיקים את כל התיקייה.

### שימוש
הדביקו קישור לפלייליסט ← בחרו מצב ואיכות ← **הורדה**. הקבצים נשמרים ב-**Downloads\YouTube Playlists** (ניתן לשנות בהגדרות).

**טיפים**
- אם יוטיוב משנה משהו וההורדה נכשלת: הגדרות ← **עדכון רכיב ההורדה**. התוכנה גם מתעדכנת אוטומטית בכל הפעלה (ניתן לכבות).
- סרטונים עם הגבלת גיל או למנויים: בהגדרות בחרו את הדפדפן שבו אתם מחוברים ליוטיוב ("עוגיות מהדפדפן").
- חלון התוכנה דורש WebView2 (קיים כברירת מחדל ב-Windows 10/11). אם חסר, התוכנה נפתחת בחלון Edge/Chrome במצב אפליקציה.
- הסרה: הגדרות Windows ← אפליקציות ← YouTube Playlist Downloader (בגרסה הניידת: מוחקים את התיקייה).

### פרטיות ואבטחה
- אין שרת מרכזי, אין חשבון ואין איסוף נתונים. כל הורדה מתבצעת ישירות מהמחשב שלכם.
- מנוע ההורדה פועל מקומית בתוך התוכנה ומאזין ל-`127.0.0.1` בלבד (פורט אקראי, לא נגיש מהרשת). בקשות נבדקות (Host / Origin / סוג תוכן) ומאתרים אחרים נחסמות, כולל דף הנחיתה.
- יומן תקלות: `%LOCALAPPDATA%\YTPlaylistDownloader\server.log` (בגרסה הניידת: `data\server.log`).

### הערה משפטית
יש להוריד רק תכנים שיש לכם זכות להוריד. השימוש באחריותכם ובהתאם לתנאי השימוש של יוטיוב ולדיני זכויות היוצרים.

## למפתחים

### מבנה
| קובץ | תפקיד |
|---|---|
| `ui/index.html`, `ui/icon.*` | הממשק של התוכנה (HTML/CSS/JS בלי תלויות) |
| `server.py` | מנוע מקומי: API, תור הורדות, yt-dlp, אריזה ל-ZIP, הגדרות והיסטוריה, הגנות |
| `app.py` | מעטפת: חלון (pywebview/WebView2), מופע יחיד, כיבוי מסודר, `--selftest` |
| `assets/`, `tools/make_icon.py` | האייקון ותסריט היצירה שלו |
| `docs/` | דף הנחיתה (GitHub Pages) |
| `installer/setup.iss` | סקריפט Inno Setup ל-`Setup.exe` |
| `.github/workflows/build-installer.yml` | בנייה, בדיקות ופרסום אוטומטיים |

הכלים `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` ו-`deno.exe` נמצאים בתיקייה `bin\` לצד התוכנה והמנוע מוצא אותם משם, בלי תלות ב-PATH. (Deno נדרש ע"י yt-dlp לפענוח אתגרי יוטיוב.)

### הרצה לפיתוח
```bash
pip install -U pywebview yt-dlp   # וגם ffmpeg ב-PATH או בתיקייה bin\ ליד server.py
python app.py                     # חלון התוכנה
python server.py                  # רק המנוע, לבדיקה בדפדפן
```
משתני סביבה לבדיקות: `YTZIP_BIN` (תיקיית כלים), `YTZIP_OUTDIR` (תיקיית פלט), `YTZIP_DATA` (תיקיית נתונים).

### בנייה ופרסום
דחיפת תג `v*` (למשל `git tag v2.0.0 && git push origin v2.0.0`) מריצה את ה-Workflow: הורדת הכלים, PyInstaller, בדיקה עצמית (ללא Python/FFmpeg ב-PATH), בניית `Setup.exe` + בדיקת התקנה והסרה בשקט, בניית ה-ZIP הנייד + בדיקה שהנתונים נשמרים לצידו, ופרסום שני הקבצים ב-Releases. אפשר גם להריץ ידנית מלשונית Actions (הקבצים יופיעו כ-Artifacts).
